# Godot 迁移评估

日期：2026-08-27

结论：当前试玩版继续使用 Phaser 3 + TypeScript + Vite，不迁移到 Godot。

依据：

- 当前版本的交付目标是手机横屏网页和 Builda 外壳试玩。现有工程已经接入触摸输入、安全区适配、网页构建和 Builda SDK。
- 当前代码和资源以网页 Canvas、相对路径图片及浏览器本地存档为基础。主战斗流程、升级状态机、30 层数据和每日挑战都已在现有工程中运行。
- 迁移到 Godot 需要重新搭建场景树、脚本状态机、触摸输入、安全区适配、资源导入、网页导出和 Builda 外壳验证。当前玩法和 UI 仍在持续调整，迁移会同时放大实现和回归范围。
- `strange-hospital/HARNESS/MAP.md` 中记录的引擎选择仍是已确认的 `basic-html`；按照引擎变更规范，正式切换前需要重新确认 Harness 和 Web 导出验收条件。

后续策略：

- Phaser/Vite 版本继续用于快速试玩、数值调整和 Builda 网页验收。
- Godot 4.7.1 程序暂不复制到项目根目录，也不作为当前 Demo 的运行依赖。
- 玩法、UI、资源规格和输入方案稳定后，再建立独立 Godot 主工程，并以同一份已确认的状态机和数据表重建。

本次未修改 Harness、未安装 Godot 工具链、未上传或发布 Builda。
