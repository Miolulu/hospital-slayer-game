## 仍由程序动态绘制

| 区域 | 当前用途 | 未直接删除的原因 |
| --- | --- | --- |
| SAN 和经验填充 | 根据实时数值改变长度 | 这是动态填充层，外框已经使用图片 |
| 排行榜滚动条 | 反映 20 名榜单的当前滚动位置 | 需要随可视行和滚动偏移实时变化 |
| 伤害数字和状态文字 | 显示实时伤害、吸收、异化和升级反馈 | 需要数字图集和三套状态标记素材后才能替换 |
| 敌人攻击预警 | 显示爆炸范围、激光方向和冲击波 | 需要带透明通道的序列帧或特效图集 |
| 画面遮罩和受击闪烁 | 页面转场、加载遮罩、SAN 受击反馈 | 属于全屏动态效果，不是 UI 底框 |
| 医生和护士 | 新手对白以外的角色兜底 | 需要正面透明立绘后才能替换 |

飞书“删除全部矢量 UI”的条目暂不勾选。静态底框已经处理完，但动态填充、滚动条、伤害反馈和攻击预警仍缺少可直接替换的最终素材。
